# echo-bat

Flappy Bird-like 2D game in Unity: a bat flying through a cave. Warm-up project before [metroidvania-slice](https://github.com/grabreu/metroidvania-slice); games are a side outlet, not a portfolio centerpiece.

**Status:** draft. Nothing is implemented yet.

## Tech stack

Unity 6000.6.7f1 (Universal 2D, URP) · C#

## Scope

Small and time-boxed. Minimum loop:

- Flap (jump, multiple times in the air).
- Scrolling obstacles that spawn over time.
- Collision ends the run.
- Score.
- Game over and restart.
